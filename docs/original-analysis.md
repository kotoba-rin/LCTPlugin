# 原文解析

在 `texts/<seminar>/original/Leçon-xx.md` 的分段 ID 旁点击“Φ”，右侧 AI 面板会创建或打开该段的“原文解析”会话。阅读视图与编辑视图均支持。需要先在插件的“AI 功能”设置中启用本机 Codex Agent。

打开后显示两部分：

1. **原文翻译**：直接将点击的原文逻辑分段翻译为中文。相邻原文仅作上下文，不并入翻译。
2. **项目现有译文**：插件按 ID 从对应译文文件直接读取并显示，保留该块完整的段下注释、建言和引用脚注。

首次只生成翻译，不主动进行词义、语法、多义、双关分析或外部检索。需要进一步讨论时，可以在会话中追问具体词语或译法。

现有译文合并多个 ID 时，面板显示完整译文及其覆盖范围，翻译范围仍为点击的原文段落。缺少译文时仍可翻译原文，并提示对应译文不可用。ID 对应多个逻辑块时会报错，避免显示错误材料。

原文解析只读取当前原文和对应译文文件，不扫描术语表或笔记目录。原文解析与同一 ID 的译文解读分别保存会话，可以继续追问或重新解析。设置中的可编辑“解读提示词”继续用于译文解读。所有结果仅供审阅，不会自动改写正文或术语表。

源码更新后需重新构建 `main.js`，并在 Obsidian 中重新加载 `Lacan Translation Helper`，原文中的按钮才会更新。
