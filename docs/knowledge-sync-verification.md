# 知识库按需同步验证记录

验证日期：2026-11-10。本地插件已重新构建并在 macOS Obsidian 中重载。

## 已实现行为

- 同一个 Base 提供文本清单与知识库两个视图，保留原有筛选和自定义配置。
- 完整词条目录可搜索标题、路径、标签、别名和正文摘录，可按分类、主题、研讨班及同步状态筛选；筛选条件随设置保存。
- 单卡同步只下载该卡及引用图片／PDF，支持同步并打开、锚点、附件补齐、更新检查和失败重试，不递归下载关联卡或课文。
- 「更新目录」旁提供「同步全部知识库」：按完整目录顺序逐卡处理，正文和附件请求均串行，整批只读取一次发布清单，支持进度和取消，不受搜索或筛选条件影响。取消或失败停止后续任务，保留已完成词条；本地修改继续跳过。
- 正文及共享附件的本地修改、未保存编辑和同步期间变化均受保护；上游移除卡保留。状态检查避让同步任务，不干扰下载进度。
- 发布脚本从同一个确定提交生成知识元数据，快照版本覆盖元数据及生成器变化；客户端兼容旧目录和离线缓存。
