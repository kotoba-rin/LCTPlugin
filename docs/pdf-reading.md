# PDF 阅读

在当前 Obsidian 仓库中加入 PDF 后，可以通过以下入口阅读：

- 点击左侧功能区的书本按钮「打开 PDF 阅读」。
- 在命令面板运行「Lacan Translation Helper: 打开 PDF 阅读」，按文件名或目录路径搜索。
- 在文件列表中右键 PDF，选择「PDF 阅读（新标签页）」。

搜索结果同时显示文件名和完整仓库路径，便于区分同名文件。选择已经打开的 PDF 时会回到原标签页，保留当前页码和缩放；文件菜单入口始终新开标签页。当前 Markdown 阅读页会保留。

## 翻页与搜索

PDF 使用 Obsidian 内置阅读器，提供页码跳转、缩放、目录与文内搜索等操作。可将 PDF 标签页与译文或笔记分屏对照，原有 PDF 链接和页码链接继续由 Obsidian 处理。

## 法语选词与翻译

PDF 正文文字层接入插件的 [法语取词](french-lookup.md)，与 Markdown 使用相同设置：

- 拖选单词显示词典释义；设置为「双击后显示释义」时，双击查询完整单词。
- 拖选短语或句子可自动翻译，也可在浮窗切换「词典 / 翻译」。
- 取词命令也适用于当前 PDF 选区，浮窗内可朗读、固定或加入欧路生词本。

翻译只使用当前选区及其起始页附近的文字上下文，沿用「AI 功能」中配置的 Agent。PDF 的工具栏、搜索框与批注输入区不会触发自动取词；原生 PDF 右键菜单保留。

扫描 PDF 可以正常查看，但需要先做 OCR、生成文字层后才能选词和翻译。本功能不包含 OCR 或整本 PDF 自动翻译。

## 安装更新

仓库内已生成 Obsidian 加载的 `main.js`。更新后，在「设置 → 第三方插件」中关闭再开启 Lacan Translation Helper，即可加载新功能。
