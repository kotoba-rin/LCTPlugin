# 法语取词与欧路生词本

在 Obsidian 的「设置 → Lacan Translation Helper → 法语取词」中配置。

- **选中后显示释义**：拖选单词或短语后显示取词浮窗；键盘 Shift + 方向键选词也可触发。
- **双击后显示释义**：仅双击单词时自动查询。双击会按完整法语词边界补齐省音和连字符，不会把 `L’identification` 拆成不完整单词。
- **命令与右键菜单**：命令面板提供「法语取词：查询选区或光标处单词」「法语取词：翻译选区并解释语法」。编辑器、Markdown 阅读、双语阅读及 PDF 文字层中，选中法语后右键可选择「法语词典查词」或「翻译选区并解释法语语法」；阅读区菜单也保留「复制」。手动右键入口不受「选中」或「双击」自动触发方式影响。
- **固定**：保留当前浮窗，便于对照阅读；按 Esc 或点击关闭按钮退出。
- **朗读**：点击音标右侧的「朗读」，使用系统法语语音朗读当前词头；翻译页朗读原选区。播放时再次点击「停止」即可中止，切换词条、标签或关闭浮窗也会停止。系统未安装法语语音时会提示安装，无需配置 API 授权码。

支持普通 Markdown 的编辑、阅读视图、插件双语阅读视图及 Obsidian 内置 PDF 阅读视图，不修改课文或术语表。PDF 需要有可选中的文字层；扫描图片需先经 OCR。打开方式见 [PDF 阅读说明](pdf-reading.md)。

双语阅读的正文显示文字光标，可拖选、复制和双击选词。法语区按上述设置触发查词或翻译；中文译文、注释和建言双击后进入整段编辑。在多个窗格或弹出窗口中，取词使用鼠标实际选中的文本和上下文。

## 法语词形与来源

保留原选区、重音、连字符和上下文；查询时可以分离明确的省音前缀。词典反查负责给出实际词头和语法信息，不通过直接删除词尾推定原形。

- `L’identification` 保留原文形式，查询 `identification`，显示原站的 `n. f.` 等标记。
- `chevaux` 显示原站匹配的 `cheval` 和复数提示。
- `étaient` 等有多个匹配项的词形会列出候选，由读者选择。
- `belles` 等形式可能还有独立词义，保留该词条与相关词形。

「词典」显示法语助手公开在线词典内容，词头、音标、语法和释义均标注来源。原站的文字字图以安全图片形式显示；无法完整显示或截短时会提示并保留原站链接。网页结构变化、访问限制或无结果会显示明确错误，不替换为编造的释义。

「翻译」使用「AI 功能」中配置的本地 Codex Agent 和模型，只发送当前选区及附近上下文，返回中文试译与相关语法说明。短语或句子可设置为自动翻译。模型生成内容与词典内容分别标注，不能视为项目定译或词典引文。该流程不检索文件、不开启网页搜索或 MCP，也不保存为普通聊天。

## 收藏到欧路法语生词本

1. 在 [法语助手授权页面](https://my.frdic.com/OpenAPI/Authorization) 获取个人欧路 API 授权码。
2. 点击「欧路 API 授权码 → 设置授权码」，粘贴完整授权码并保存；插件设置只保存密钥名称。
3. 点击「读取生词本」，选择收藏目标。
4. 在取词浮窗中确认词条后点击「加入生词本」。已经反查到词元时收藏词典确认的词元；多义反查未选择候选前不自动收藏。

浮窗会通过 API 查询该词在当前所选生词本中的状态；添加后再次回读确认，确认收录后显示「已加入」。重新查词时也会读取最新状态，以反映其他设备上的添加或移除。回读失败或服务端尚未确认收录时，按钮显示「重试同步」，再次点击只读取状态，不重复提交添加。

生词本通过欧路官方 OpenAPI 读写，语言固定为 `fr`。查询词典不需要生词本授权码。未配置授权码时，可正常查词和翻译，收藏按钮会给出配置提示。

旧版 Obsidian 若没有密钥存储，只提供本次运行有效的密码输入，不将授权码写入插件的 `data.json`。不要将授权码发送到聊天或提交到 Git。
